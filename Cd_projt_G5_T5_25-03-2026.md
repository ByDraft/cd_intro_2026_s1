<h1 align="center"> Predicción de notas de estudiantes <h1>


<h3> Este proyecto tiene como objetivo predecir las notas finales de estudiantes a partir de variables como horas de estudio, asistencia a clase y participación. <h3>

<h3 align="center"> Objetivo </h3>
<p>Identificar los factores que influyen en el rendimiento académico y generar un modelo predictivo.</p>

<h3 align="center"> Datos utilizados </h3>
<p align="center">|-Horas de estudio por semana|  </p>
<p align="center">|-Tiempo dedicado al estudio|  </p>
<p align="center">|-Asistencia a clases|  </p>
<p align="center">|-Porcentaje de asistencia|  </p>
<p align="center">|-Número de tareas entregadas|  </p>
<p align="center">|-Cantidad de trabajos realizados|  </p>
<p align="center">|-Participación en clase|  </p>

<h3 align="center">Metodología</h3>
<p align="center">1. Recolección de datos  </p>
<p align="center">2. Limpieza de datos  </p>  
<p align="center">3. Análisis de datos para entender las variables  </p>
<p align="center">4. Aplicación de modelo para predecir la nota final  </p>

<h3 align=center>Resultados esperados</h3>
<p align="center">Se espera predecir la nota final de los estudiantes y determinar las variables más importantes.</p>

<h2 align="center">Conclusiones</h2>
<p>
  El proyecto permite entender cómo diferentes variables afectan el rendimiento académico y muestra el uso básico de modelos predictivos.
</p>
